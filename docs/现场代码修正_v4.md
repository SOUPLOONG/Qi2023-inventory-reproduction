# V4：修正了什么，哪些仍然只是工程扩展

V3现场只修改b/h重训，训练仍是1—4天提前期、需求全部积欠，测试却改为2—8天、可能交叉、部分需求丢失。V4保留这个策略作`V3_Transfer`，不再把它当作匹配环境的训练结果。

## 一、将环境条件拆开

`engine.plan`与`simulate`现在显式支持`lead_scale=1/2`、`shortage_mode=backorder/hybrid`。两项可以独立改变，四种组合均保存实际结果。特征使用与环境一致的已完成供应商历史；不匹配时程序拒绝执行。

离线闭式OPT不再被允许用于交叉或混合缺货环境。Theorem 1的标签仍保留给论文原假设下的离线实验，不能把它的正确性推广到另一组假设。

## 二、现场不套用失效的标签

新增`field_calibration.py`。现场校准头在真实逐日库存与在途队列中，通过持有成本+缺货成本反向传播训练。需求、到货过程、丢失需求规则以及h=12、b=88在训练和目标验证/测试中一致。

校准策略为：

`订货量 = max(Normal基库存目标 + scale × 校准值 − 净库存 − 在途总量, 0)`。

校准值由一个64→32→1的神经网络给出，经tanh限制在±8个scale单位。它接收冻结的MQ-RNN融合表示、历史需求和供应特征、review、Normal目标及可观测库存状态。输入149维上下文+3维库存量，共152维。

最后一层初始权重和偏置均为0，因此初始策略等于Normal，验证时把这个epoch0也作为候选。这只保证选择出的模型不劣于其验证集基线，不保证未来测试集也更好。

**这是Normal残差校准的工程扩展，不是作者原神经网络或原训练方法的精确还原。** 冻结编码器是已有离线MQ-RNN，新增训练的是现场校准头。不能将改进后的表现归功于论文原始监督模型本身。

## 三、时间与信息集

- 冻结编码器的训练/选择信息最晚截至第329天。
- 现场成本训练：第220—279天，之前第200—219天由Normal预热。
- 校准验证：第330—359天，之前第300—329天Normal预热。
- 最终诊断测试：第370—399天；所有策略从第300天开始连续Normal历史，保留在途订单与库存，再于370天切换。
- 训练、验证是359日信息截止后的回顾建模，不宣称该模型在220日当时就能部署。
- 在线模型只见净库存和**在途总数量**，不见模拟器知道的实际未来到货日；队列按真实到货日排列只用于训练环境演化。
- 未来需求和实际提前期用于历史轨迹成本计算，未进入当时的动作输入。未来日历和计划促销仍采用事先已知的假设。

## 四、控制实验与选择规则

`V4_OfflineCalibrator`在1—4天/完全积欠环境训练，`V4_MatchedCalibrator`在2—8天/hybrid环境训练。两者结构、初始化、训练预算相同，均按**同一个目标现场验证环境**挑选轮次。这样比较的是训练环境变化，不再混入验证环境变化。

主评估将Normal、V3迁移策略、离线训练校准策略、匹配训练校准策略放到相同商品、相同需求、相同初始库存/在途订单上逐一模拟，输出配对成本差及区间。PSM、回归和DID另行保留为论文统计流程的模拟示例，不把两个不同匹配组的均值差与同商品配对效果混为一谈。

旧测试期已参与过V3问题诊断，因此V4的该期间结果应视为修正后的诊断评估，不是全新盲测。新增三个事先固定的独立面板种子20261020、20261021、20261022，仅做评估；不会据其结果重新挑选权重。标准版每个面板1,000条序列，quick每个80条。新面板数值ID可与原面板重合，但没有基于ID的商品嵌入，实际生成的轨迹独立。

## 五、检查与缓存

- 两套独立模拟器（NumPy、Torch）在四种环境下核对逐商品成本和订单。
- 用中心有限差分独立验证autograd，使用连续需求避免恰落不可导折点。
- 扰动未来真实需求/提前期，核验当前可观测特征和当前动作不变。
- 核验非负订货、初始Normal策略、完整逐日成本和含丢失需求的库存平衡。
- 缓存同时包含完整面板数组摘要、原训练样本摘要、冻结编码器权重文件摘要、环境和预算、相关源码摘要。验证期数据变化也会使缓存失效。

匹配环境只修正训练设定错误，不能保证神经网络泛化更好。有限训练、需求季节变化、特征表达、非凸优化和策略状态分布都可能影响成本。任何未达到的降本结论都应按实际结果保留；数据仍是合成数据，不等同于京东现场证据。

## 六、本次仍未解决的表现差距

标准面板的验证期平均需求约14.05，最终测试期约17.90，高约27.4%。供应和缺货规则匹配，并不意味着需求状态分布不变。V4同商品测试成本相对旧迁移策略下降约6.20%，但仍比Normal高约16.89%；三个额外独立面板也没有恢复优于Normal的结论。离线训练校准控制有时优于匹配校准，所以当前证据不支持“环境匹配本身必然带来更好泛化”。

需求变化是一条解释线索，不是通过消融证明的唯一原因。以后若继续调整，应以新的训练/验证设计改进泛化，并重新保留未用于诊断的独立评估，不能按当前测试排序挑权重。本次不把程序正确性验证或相对V3的部分改进写成论文所有结论成功复现。
