# 一边理解，一边复现

建议按下列顺序，不必先学完所有深度学习。

1. **库存记账**：先打开教学Notebook运行手算例子。I为库存，负数表示尚未满足的需求。每天先收货，再面对需求；余货付h，欠货付b。弄清“订货日”和“到货日”不同。
2. **一条订单的最优数量**：阅读《公式与代码对应》的闭式例子。累计需求、min/max、正部、求和、向下取整分别做什么，都可以拿6天数据检查。
3. **为什么需要学习**：事后能看到真实未来而求a*；上线时不知道未来，只能用历史x学映射f(x)。训练标签和预测输入要分开，否则就是偷看答案。
4. **求导与训练**：在Notebook运行y=w×x的例子。导数是参数变化一点时损失变化多快；朝负梯度走可局部降低损失。再看training.py中zero_grad、backward和step三个动作。
5. **三条输出**：订货量是主任务，需求与供应商提前期是辅助任务。为什么需求预测准不一定库存成本低？低估和高估的代价不同，且多期库存会把误差传下去。
6. **Figure 2**：先看三个固定商品的分位带；再看全部商品的成本表。某张预测图好看不等于全部商品表现好，所以必须保存全体成本。
7. **对照方法**：Normal、Gamma先假定需求分布，BM1预测累计需求、BM2预测每日需求再做优化，GBM和神经网络都直接学习订货标签。OPT是看见未来的参照，不是可上线算法。
8. **附录实验**：每次只改变层数、隐藏单元、学习率、数据量、成本比或随机种子。不要预设曲线一定单调，也不要只展示最好的随机种子。
9. **现场统计**：先有真实策略产生的库存结果，再匹配和回归。用干预前变量匹配，DID为“处理组变化−对照组变化”。合成数据的显著结果只说明模拟设定下的结果。
